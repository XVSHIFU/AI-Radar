# 连续时间线融合预览与全局中英文

2026-09-15。本记录保存本轮用户明确提出的细化方向和代码实现边界，供预览复核与后续迭代使用。时间线与品牌候选仍处于比较阶段；本文不构成正式首页布局替换、品牌定稿、公开部署或真实采集链路验收。

## 用户确认的细化方向

以原有连续时间线为主体，保留事件沿时间展开的阅读顺序。吸收各提案中用户选中的局部特点：

| 来源 | 本轮采用的特点 | 在融合预览中的表达 |
| --- | --- | --- |
| 原首页 | 连续时间线 | 一条贯穿的时间轴和事件节点，保留年、月、日层级 |
| C | 日期在侧边 | 日期移至时间轴旁，正文列集中承载事件内容 |
| A | 清楚的分类 | 分类入口和事件分类标签保持可见、可辨认 |
| B | 适度留白、便于阅读、细分隔线 | 舒展与紧凑两档密度；标题、摘要与元信息分层，事件之间使用细线 |
| D | 重点事件明确 | 重点事件使用实心节点和较重标题；不另造第二套排序语义 |

这是对原布局的局部融合，不能据此推断用户批准了 A、B、C 或 D 的整套全站方案。保留真实日期范围日历；日期选择仍使用现有 `DateRangePicker` 的状态与交互，不将日历改成装饰性图片或仅有快捷日期的替代界面。

## 预览入口与布局边界

- `/timeline-preview`：融合阅读预览，共用真实首页组件、筛选、日期范围和事件交互；顶部提供「舒展 / 紧凑」、品牌比较和返回当前首页。
- `/brand-preview`：比较 8 款原创 SVG，可把所选标记放进预览导航与时间线观察。候选为信号刻度、轨道交汇、时间脉络、观察窗口、新知地平线、聚焦、生长分支、知识接力。
- `/`：继续承载当前正式首页布局。预览的侧边日期、阅读密度和品牌候选不自动替换正式首页。
- 使用 `?demo=1` 时，预览之间的导航保留演示参数。日期筛选更新保留当前预览路由，避免操作日历后意外返回正式首页。

品牌候选以代码中的原创 SVG 路径表达，颜色沿用主题的 `currentColor`。比较页同时展示独立标记、品牌组合和 16px 标签页尺寸。03「时间脉络」与 04「观察窗口」只是优先比较建议，尚无正式选定结果。

融合样式限定在预览作用域。桌面日期列位于连续轴左侧；窄屏缩减日期列占用空间，隐藏辅助加载数量，保持主阅读列可用。1200px 以下让出右侧辅助栏，600px 以下使用单列品牌比较。现有分类、搜索与日历筛选继续提供实际功能。

## 本轮预览审查修复

品牌候选处于按钮内，曾受全局按钮 SVG 尺寸规则影响，导致展示尺寸与独立标记、组合标记、标签页的用途不符。本轮在品牌预览作用域明确约束相应 SVG 为 64px、28px、16px；900px 以下独立展示标记为 48px，并显式保留节点填色。修复针对候选展示，不改变全站按钮图标规范。

日期侧注在桌面与手机分别分配空间，避免直接照搬桌面列宽。预览保留真实日历组件与筛选更新逻辑。后续截图复核须同时检查日历展开、日期筛选后仍停留预览路由，以及 16px 标记是否清楚；不能仅凭静态首屏判断完成。

## 动效的当前实现

当前值见 [motion.ts](../frontend/src/motion.ts)、[style.css](../frontend/src/style.css)、[AssistantPanel.vue](../frontend/src/AssistantPanel.vue) 与 [EventDrawers.vue](../frontend/src/EventDrawers.vue)。这些值更新了先前动效验收文档中的 420ms / 260ms 和浮标上移 2px 的记录。

| 对象 | 当前行为 |
| --- | --- |
| 抽屉与助手进入 | 680ms，缓出曲线 `cubic-bezier(.22,.7,.2,1)` |
| 抽屉与助手退出 | 460ms；抽屉退出仍保留遮罩和生命周期管理 |
| 减少动态偏好 | 120ms 透明度过渡，关闭位移与圆形裁切动效 |
| 助手浮标悬停 | 上移 5px、轻微放大至 1.04；减少动态时取消变换 |
| 助手展开范围 | 从浮标实际中心计算面板最远角距离，补 2px，作为圆形展开半径 |
| 助手收起透明度 | 退出末段 120ms 才淡出，标准退出时延迟 340ms；让收缩过程保持可见 |

测量展开原点时临时移除浮标的悬停变换，防止浮标上移影响起点。半径由实际面板宽度、视口高度和原点计算，避免使用固定超大裁切半径造成进入和退出节奏失真。

## 全局中文 / English

语言切换与主题轮放在同一入口区域。共享响应式语言状态提供 `zh` / `en`，默认中文，使用 `ai-radar-locale` 保存浏览器偏好；存储不可用时仍可在当前会话切换。切换同步 `html.lang` 为 `zh-CN` / `en`，日期与数值格式使用相应区域设置。

语言适配覆盖应用导航、时间线和品牌预览、筛选与日历、统计与问答、事件与来源抽屉、研究助手，以及管理后台。后台的登录、来源管理、批量探测、采集记录、模型设置和用量标签使用正常 Vue 响应式文本。已有操作通知和模型测试状态在切换语言后仍可重新渲染，用户不必再次发起请求。常见错误和状态提供对应文案；未知诊断保留原文。

字体按语言选择回退栈：英文使用 Inter、系统无衬线与 Segoe UI 等回退；中文使用 Inter、Noto Sans SC、苹方和微软雅黑等回退。这里记录的是 CSS 字体选择，不能据此声称所有设备已安装或加载其中每一种字体。

语言切换作用于界面文案，不新增模型翻译请求。已采集事件标题、摘要、来源正文、证据摘录、问答内容、模型测试请求与返回原文、原始诊断、来源名称、URL、服务商和模型标识保持其数据语义与原始内容。界面语言和来源原文的显示偏好分别处理；切换界面语言不会把采集内容改写成另一种语言。

实现依据：[locale.ts](../frontend/src/locale.ts)、[reading-locale.ts](../frontend/src/reading-locale.ts)、[admin-locale.ts](../frontend/src/admin-locale.ts)、[HomePage.vue](../frontend/src/HomePage.vue)、[TimelinePreviewBar.vue](../frontend/src/TimelinePreviewBar.vue)、[BrandPreview.vue](../frontend/src/BrandPreview.vue)、[brand-preview.ts](../frontend/src/brand-preview.ts)、[timeline-preview.css](../frontend/src/timeline-preview.css)。
