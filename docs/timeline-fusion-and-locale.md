2026-09-15。用户已选定舒展时间线为唯一布局，并选定 03「时间脉络」用于导航标记与 favicon。本轮将布局应用到正式首页 `/`，保留 `/timeline-preview` 作为同一布局的查看入口。字体方案尚未选定，仍在独立 `/type-preview` 中比较。以下记录实现与初轮检查边界，不构成最终验证、公开部署或真实采集链路验收。

## 用户确认的细化方向

以原有连续时间线为主体，保留事件沿时间展开的阅读顺序。吸收各提案中用户选中的局部特点：

| 来源 | 本轮采用的特点 | 在融合预览中的表达 |
| --- | --- | --- |
| 原首页 | 连续时间线 | 一条贯穿的时间轴和事件节点，保留年、月、日层级 |
| C | 日期在侧边 | 日期移至时间轴旁，正文列集中承载事件内容 |
| A | 清楚的分类 | 分类入口和事件分类标签保持可见、可辨认 |
| B | 适度留白、便于阅读、细分隔线 | 用户选定舒展为唯一密度；标题、摘要与元信息分层，事件之间使用细线 |
| D | 重点事件明确 | 重点事件使用实心节点和较重标题；不另造第二套排序语义 |

这是对原布局的局部融合，不能据此推断用户批准了 A、B、C 或 D 的整套全站方案。保留真实日期范围日历；日期选择仍使用现有 `DateRangePicker` 的状态与交互，不将日历改成装饰性图片或仅有快捷日期的替代界面。

## 正式布局与保留入口

- `/`：应用用户选定的舒展连续时间线。保留年、月、日层级、真实筛选、日期范围日历与事件抽屉；不再提供舒展/紧凑密度切换。
- `/timeline-preview`：保留查看入口，与正式首页共用选定布局和功能，不再作为另一套密度方案。通过入口可以继续进入品牌及字体比较。
- `/brand-preview`：保留8款原创SVG的历史比较页面；03「时间脉络」已选定，不能再描述为尚无定稿。其余候选不是新的生产品牌。
- `/type-preview`：独立字体比较页面；切换方案仅改变固定样本，不修改正式首页或全站字体。
- `?demo=1`继续标识演示模式；预览导航及日期筛选保留适用路由和参数。日历仍使用真实DateRangePicker的状态与交互。

摘要最多显示4行，完整内容通过既有事件阅读入口查看。月、日折叠采用SVG指示符，并对齐相应日期和折叠入口；连续轴、节点与正文列保留清楚的层级。桌面日期位于轴旁；窄屏压缩侧注空间、隐藏辅助加载数量，保证主要阅读列可用。1200px以下让出右侧辅助栏，品牌比较在600px以下为单列。

导航RadarMark使用03「时间脉络」原创路径并继承主题currentColor；favicon使用同一几何的白色小尺寸标记与固定底色。来源说明见[SVG provenance](../frontend/public/icons/README.md)。既有Lucide原始素材与许可保留，但不再把生产导航标记描述为Lucide radar。

## 字体比较：正式字体未选

`/type-preview`提供同一份中文、英文和混排文案及数字、控件样本，保持可比字号与内容；控制区保留易读黑体。页面文案是排版样本，不是新收录事件。

| 方案 | 标题 | 正文 |
| --- | --- | --- |
| A · 清晰黑体 | Noto Sans SC / Inter | Noto Sans SC / Inter |
| B · 杂志标题 | Noto Serif SC / Source Serif 4 | Noto Sans SC / Inter |
| C · 书刊宋体 | Noto Serif SC / Source Serif 4 | Noto Serif SC / Source Serif 4 |
| D · 温润楷体 | LXGW WenKai / Source Serif 4 | LXGW WenKai / Source Serif 4 |

六款字体通过本地WOFF2自托管，只覆盖固定样本文字、可打印ASCII与常见中文标点。样本文字变化需要重新生成子集；不能据此声称支持任意新闻全文，也不能将预览字体直接作为正式全站字体。正式字体选择仍待用户决定。

来源为Google Fonts官方仓库与LXGW WenKai官方发行，使用fontTools本地裁剪，没有把项目文本发到字体服务。具体版本、许可及输入/输出SHA-256见[字体来源清单](../frontend/public/type-studies/fonts/README.md)及同目录manifest.json；固定字符来源为type-specimen.txt。实现见[TypePreview.vue](../frontend/src/TypePreview.vue)与[type-preview.css](../frontend/src/type-preview.css)。

## 动效的当前实现

当前值见 [motion.ts](../frontend/src/motion.ts)、[style.css](../frontend/src/style.css)、[AssistantPanel.vue](../frontend/src/AssistantPanel.vue) 与 [EventDrawers.vue](../frontend/src/EventDrawers.vue)。本轮将抽屉与助手时长分开；旧记录中两者统一680ms / 460ms的描述已不适用于抽屉。

| 对象 | 当前行为 |
| --- | --- |
| 抽屉进入 / 退出 | 380ms / 260ms；退出仍保留遮罩和生命周期管理 |
| 助手进入 / 退出 | 680ms / 460ms；保留浮标原点的圆形展开与收回，高光已减弱 |
| 减少动态偏好 | 120ms 透明度过渡，关闭位移与圆形裁切动效 |
| 助手浮标悬停 | 上移 5px、轻微放大至 1.04；减少动态时取消变换 |
| 助手展开范围 | 从浮标实际中心计算面板最远角距离，补 2px，作为圆形展开半径 |
| 助手收起透明度 | 退出末段 120ms 才淡出，标准退出时延迟 340ms；让收缩过程保持可见 |

抽屉打开时保留滚动条占位并固定背景页面，关闭恢复原有滚动位置，避免滚动条消失引起横向跳动。该滚动稳定处理与抽屉动画生命周期配合，不改变事件/来源层的既有浏览路径。

测量展开原点时临时移除浮标的悬停变换，防止浮标上移影响起点。半径由实际面板宽度、视口高度和原点计算，避免使用固定超大裁切半径造成进入和退出节奏失真。

## 全局中文 / English

语言切换与主题轮放在同一入口区域。本轮缩小轮盘内语言文字（桌面11px），去掉左右提示文字；移动语言按钮仍保留44px最小高度。共享响应式语言状态提供 `zh` / `en`，默认中文，使用 `ai-radar-locale` 保存浏览器偏好；存储不可用时仍可在当前会话切换。切换同步 `html.lang` 为 `zh-CN` / `en`，日期与数值格式使用相应区域设置。

语言适配覆盖应用导航、时间线和品牌预览、筛选与日历、统计与问答、事件与来源抽屉、研究助手，以及管理后台。后台的登录、来源管理、批量探测、采集记录、模型设置和用量标签使用正常 Vue 响应式文本。已有操作通知和模型测试状态在切换语言后仍可重新渲染，用户不必再次发起请求。常见错误和状态提供对应文案；未知诊断保留原文。

字体按语言选择回退栈：英文使用 Inter、系统无衬线与 Segoe UI 等回退；中文使用 Inter、Noto Sans SC、苹方和微软雅黑等回退。这里记录的是 CSS 字体选择，不能据此声称所有设备已安装或加载其中每一种字体。

语言切换作用于界面文案，不新增模型翻译请求。已采集事件标题、摘要、来源正文、证据摘录、问答内容、模型测试请求与返回原文、原始诊断、来源名称、URL、服务商和模型标识保持其数据语义与原始内容。界面语言和来源原文的显示偏好分别处理；切换界面语言不会把采集内容改写成另一种语言。
