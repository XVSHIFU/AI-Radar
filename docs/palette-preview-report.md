## 设计方向
保持现有阅读空间、首页优先、并排助手和浅色界面；使用相同布局与内容比较色彩，避免布局变化影响选择。
- A 雾白钴蓝：中性灰白、钴蓝操作色，清晰稳妥。
- B 暖纸松绿：纸色背景、松绿色操作色，适合长时间阅读。
- C 雾紫墨蓝：灰紫背景、柔紫操作色，个性更鲜明。
- D 燕麦陶红：暖燕麦背景、陶红操作色，偏编辑阅读气质。
- E 冰川青：浅青背景、深青操作色，清爽明净。
推荐优先比较 A 与 B。热力图保留相同红色数量刻度和数值标签，以便跨主题理解相同数据；状态均保留文字含义。
