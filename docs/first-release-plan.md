## 目标与已有基础

首版目标：一个不配置模型也能自动更新的 AI 资讯汇总站，代码可在 GitHub 维护，版本镜像可在阿里云 ACR 拉取，通过 Docker Compose 在用户云服务器完成试部署。

现有基础：主题化前台、时间线和统计、后台来源管理、脚本采集与冻结原文、全文/向量检索、pi 研究助手、受限 gVisor Python、手动/自动内容工作台、容器部署和同机备份均已有实现。最近前端部署为 d0838af；内容后端为 f986461。当前付费提取与免费采集均停用，内容 Agent 自动模式关闭。

产品默认改为“抓取 → 清洗和去重 → 自动收录 → 展示”。AI 中文摘要、翻译、人工精选和内容 Agent 都是可选增强，不阻塞资讯发布。原文标题保留语言，来源简介和原文摘录不冒称 AI 摘要。

## 发行形式

发行单元是“一套版本一致的镜像 + Compose”，延续数据库、网关、应用和可选 Agent 的合理分离，不把所有服务塞进一个容器。基础模式负责采集、浏览、搜索和后台；AI 问答、向量和 Python 为可选能力，避免小服务器为了普通资讯聚合承担所有资源开销。

阿里云用于托管 ACR 镜像；用户自己的云服务器拉取对应版本部署。服务器不要求是阿里云。实际仓库域名以 ACR 控制台为准，不在模板写死地区或个人命名空间。首版优先目标服务器架构，其他架构验证后再支持。

ACR 支持 Docker 登录、推送和拉取，见 [阿里云官方个人版说明](https://www.alibabacloud.com/help/zh/acr/user-guide/use-a-container-registry-personal-edition-instance-to-push-and-pull-images)。若服务器使用阿里云 ECS，公网端口还需核对 [安全组规则](https://www.alibabacloud.com/help/en/ecs/user-guide/security-group-rules)。仓库版本、可用地域、访问方式及成本在选定账号和实例后确认，本计划不承诺免费配额。
