# 助手精简、抽屉圆角与模型用量核查

日期：2026-09-15；实时页面：http://192.168.194.129:5173/ 。

## 界面变更与原因

抽屉外层原有 16px 圆角，但内部 drawer-shell/header 未裁切，导致白色背景盖住顶部圆角。
现各层统一圆角并裁切内部背景；手机以 8px 外边距保留同样的四角。

助手以对话为主：每轮保留角色和小型数据标识，范围、查询计划、原始诊断、
覆盖与引用统计合为一个可反复开合的“详情”。模拟与不完整覆盖仍明确提示。
常用收起、预览、历史、新建采用带 title/aria-label 的 SVG 图标。
错误正文用简短中文，原始错误码保留在详情。没有把未实现的问答伪装成模型回答。
保存格式、范围快照、历史、附件和 Markdown 功能保留。

## 浏览器验收

按照 Impeccable distill 进行一批桌面/手机检查、一次修正和确认，未改全站配色。

- 桌面 1680×983、手机 390×844：抽屉四角 16px，overflow:hidden，无页面横向溢出。
- 正常 HTTP 页面可打开助手、加入真实事件附件；手机加入后返回助手。
- 发送“分析”得到后端 QUERY_UNSUPPORTED；默认只显示中文，详情内仍能找到原始码、查询计划与附件状态。
- 每轮只有一个详情入口，展开和收起均正常。
- Ctrl+Enter 换行、Enter 发送；草稿预览与消息中的 Markdown 标题正常。
- 第二条用户消息距会话视口顶部 0px；刷新后 4 条消息（两轮）恢复。
- 历史栏能开合；图标有操作名称和提示；无未捕获浏览器异常。
- 前端 31 个测试及生产构建通过。此次浏览器请求没有调用真实生成模型。

## 模型真实用途

当前配置仅允许 deepseek-flash，单次最大输出 1600 tokens，thinking disabled。
输入为已抓取文章的标题与冻结段落，输出为中文标题、摘要、分类、重要度、实体和候选引文。
脚本发现/下载、保存原文、字段与逐字引文校验、页面查询和统计不调用模型。

同一文章版本的提取 claim 去重；后续定时批次处理尚未提取的版本，页面刷新不会重复调用模型。
查询计划当前主要是确定性规则；研究助手 /api/v1/ask 的真实回答生成仍未实现。
截图中的 QUERY_UNSUPPORTED 属于规则解析失败，不是付费模型返回。

原方案后续还包括必要时模型辅助查询理解、基于库内 Evidence 的回答与引用核验；
embedding 为独立适配，不等于当前 Flash 提取，也尚未启用。
当前不声称跨站事件已完整归并或引文已通过语义核验。
