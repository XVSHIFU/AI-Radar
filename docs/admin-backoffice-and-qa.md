# 管理员后台与真实问答交付

验收日期：2026-09-15（Asia/Shanghai）。环境：Ubuntu 私有网络开发实例。

## 使用

后台：[http://192.168.194.129:5173/ingest](http://192.168.194.129:5173/ingest)。
管理口令沿用 Ubuntu /home/xvsf/ai-radar/.env 中 ADMIN_TOKEN，不在聊天、网页响应或 Git 中输出。
登录后会话有效8小时，退出或 API 重启使会话失效。公众事件、统计和研究助手不要求注册。

来源页支持启停、健康探测、新增/编辑自定义 RSS；新增默认停用。内置8个来源绑定适配器，
名称/入口只读。RSS 探测验证可解析条目；归档探测只报告页面可达，不等于历史抓取完整。
采集记录页手动选择已启用 RSS 并提交持久任务；内置归档历史回填仍走专用定时脚本。
停用不删除历史，也不强行取消已发出的网络请求。

模型页固定使用已授权的 DeepSeek 官方 deepseek-flash。可更新密钥、启停和输出上限1–2000。
留空密钥保留已有值；修改保存在 /home/xvsf/.config/ai-radar/model.json（0600、原子替换），
文件不存在时使用 .env。损坏配置返回受控错误，不回退为启用。配置供后续提取批次和问答读取。
连接检查不生成内容；回答测试会请求简短 JSON 并入账。测试使用已保存配置。
用量按用途与状态分组；没有提供商 token 的历史失败保留“未知”，不记成0或推算费用。

研究助手：从事件抽屉“加入当前对话”，输入“分析”并 Enter 发送。
JSON 回答使用当前筛选/附件范围和冻结证据；最多取回20事件、60段证据，序列化上下文不超过48000字符。
历史最多使用最近4条、每条1000字符，并可因总上限省略。统计仍完全由数据库计算，不调用模型。
引用编号、URL、标题和逐字摘录由服务器从库内证据对应；越界/缺失引用或非合约输出拒绝。
完整覆盖要求实际引用涉及全部范围事件；部分取回或只总结部分事件显示 partial。
引用存在性校验不等于独立语义事实核验，模型仍可能误解原文。

## 保护和限制

- 管理接口独立鉴权；HttpOnly / SameSite=Strict cookie，写操作 CSRF；CLI Bearer 保持兼容。
- 口令失败限流、会话数量上限、no-store；浏览器不存管理口令或 API 密钥。
- 来源 URL/DNS/重定向和实际连接均限制公共地址，禁用环境代理，防止后台探测访问内部服务。
- 问答同一请求ID写入唯一账本，不自动再次付费；重复返回409，取消后不能假定提供商未计费。
- 单 API 进程最多2个并发问答、每地址每分钟6次、总计每分钟30次；当前开发代理可能共享客户端地址。
- 真实 SSE、复杂问句的模型计划、多实例会话、后台操作审计和公网 TLS 尚未交付。
  当前仅使用授权的虚拟机开发地址，不据此声称公网生产验收完成。
- 并发探测与同时编辑来源还有轻微健康状态竞态；后续使用任务锁/配置版本消除。
