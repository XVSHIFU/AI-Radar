# 四页 UI 重设计验收

本轮沿用工程，按用户确认的「桌面阅读空间 + 云层切面 + 动作谱」重做四页。首页优先阅读 AI 动态，再筛选、问答和核查证据。桌面阅读空间负责布局；云层切面转化为浅蓝底、白色阅读面与展开的证据层；动作谱转化为日期索引和纵向节奏。没有额外堆叠装饰图片。

## 范围与行为

- 首页：左侧导航、连续日期事件流、完整库的分类统计；手机收拢次要筛选。
- 详情：限制标题阅读宽度，分隔摘要、实体与证据；原文摘录仍可展开并定位。
- 问答：问题输入优先，保留条件、实际计划、流式回答、取消、错误和引用定位。
- 采集管理：统一表单与状态布局；管理令牌只存当前页面内存。

本轮只更改前端表现。合成样本和模拟回答保持明确标注；真实数据库、历史来源样本和真实模型验收仍按原验收表待完成。
