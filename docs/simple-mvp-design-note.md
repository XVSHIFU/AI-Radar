# 简化阅读预览 MVP · 设计记录

本记录仅描述 `/preview` 与 `/preview/ask` 的比较方案，依据 2026-09-14 的实际组件、CSS 层叠与已有第二轮截图记录。它是现有银蓝阅读世界的局部扩展；正式规则仍见 [DESIGN.md](../DESIGN.md)，本次不更新该文件或 `.impeccable/design.json`。视觉完成结论由独立审查另行给出。

## Overview

用户确认的核心取舍是：打开事件即可阅读保存的证据，来源细节按需展开。预览把主流程压缩为“读动态 → 搜索或分类 → 打开事件 → 核对摘录 → 关闭”，保留准确范围和材料缺失的文字。

| 原版组织 | 预览实际变化 |
| --- | --- |
| 固定侧导航、阅读面与上下文列 | 顶部“AI 动态 / 问答”导航，单列内容；维护入口在页脚 |
| 分层日期占据独立纵向空间 | 年与首个月同行，日期下直接接连续事件；年/月/日仍可折叠 |
| 事件、来源、证据三层抽屉 | 单个原生模态阅读窗；所有返回的保存摘录直接显示，版本、段落和核验状态折叠 |
| 问答条件及研究说明常显 | 问题优先，研究条件默认收起，说明变为一行正文；答案与引用交互沿用原页 |

## Colors

沿用运行时颜色：银蓝地面 `#edf2f7`、白色阅读面 `#fff`、深墨正文 `#10223b`、灰蓝辅助文字 `#5b6d82`、深蓝交互 `#123d73`、分隔线 `#d4dee9`。分类与实体沿用浅青底 `#dceff0` / 深青字 `#075f68`，摘录沿用 `#f3f7fb` 底与 `#9db5ca` 左边线。合成标识保留现有浅黄色及明确说明，不建立新色系。

## Typography

继承 Inter、PingFang SC、Microsoft YaHei、sans-serif，无新字体资源。预览页标题为 `clamp(28px, 4vw, 38px)`、行高 `1.12`；动态页标题未显式增加字重，问答标题继续继承原 `.page-title` 的 `600`。事件标题为 `19px / 400 / 1.4`，摘要行高 `1.55`。阅读窗标题桌面 `26px`、手机 `22px`，字重 `600`、行高 `1.28`；阅读正文行高 `1.7`。辅助信息 `13px`、标签 `12px`；年份 `20px / 650`，手机 `18px`。

## Layout

顶部容器最大宽度 `1180px`；内容容器最大宽度 `920px`，内边距 `18px 24px 28px`。首页白色阅读面内边距 `14px 28px 24px`，事件以细线连续排列，不加独立卡片。搜索与分类并列，日期在原生展开区中显示；选定日期仍出现在折叠摘要中。问答最大宽度 `760px`，阅读容器透明、无阴影、无额外内边距。

预览主要断点为 `700px`：导航转两行，搜索与分类上下排列；内容内边距 `12px 16px 20px`，阅读面 `10px 16px 18px`，年份/月计数隐藏但日期计数保留。问答条件由三列变一列。原全局 `900px` 规则仍作用于共享元素，不能把预览断点当作全站替换。

阅读窗桌面右侧及上下距视口 `24px`，宽 `min(680px, calc(100vw - 48px))`，高 `calc(100dvh - 48px)`；正文独立滚动、内边距 `24px`。`700px` 及以下全屏无圆角，正文内边距 `20px`。

## Elevation & Depth

首页阅读面复用 `0 12px 30px rgba(34, 61, 93, 0.08)` 阴影；阅读窗复用 `-18px 10px 34px rgba(34, 61, 93, 0.16)`，遮罩为 `rgba(16, 34, 59, 0.16)`。日期浮层使用同方向、透明度 `0.12` 的柔和阴影。阅读窗进入沿用 `14px` 水平位移、`0.2s`；日期按钮指示符过渡 `0.18s`，减少动态效果时关闭；日期筛选、来源信息和研究条件新增的展开箭头同为 `0.18s`。

## Shapes

阅读面与桌面阅读窗圆角 `16px`，字段和日期浮层 `8px`，标签 `999px`。事件节点实际外尺寸 `7px`、描边 `2px`，只连接阅读节奏。预览活动导航继承全局 `2px` 深蓝底线；原版侧轨道的“去掉底线”规则仅属于原版。

## Components

- **展开控件**：日期、来源信息、研究条件均使用 `7px`、`1.5px` 细边线箭头；关闭朝右、展开朝下，原生 marker 隐藏。清除按钮最小高度已回到 `44px`。
- **筛选与范围**：输入或选择后等待 `260ms` 更新 URL 与列表，取消旧请求。匹配总数采用服务端 `total`；日期组明确写“已加载”，分页采用服务端游标。无效日期、无结果、加载与失败各有文字，失败可重试。
- **事件阅读**：普通点击在 `/preview?event=…` 打开单个原生 `dialog`；修改键和新标签打开继续走完整事件地址。开启时聚焦关闭按钮、锁住底层滚动；关闭或 Esc 移除事件参数并恢复可用触发点焦点，异步读取有取消及代次守卫。
- **证据优先**：直接呈现 API 返回的每条摘录，不由前端筛选“最关键”或赋予支持排名。每条保留来源标题和安全 HTTP(S) 链接；“来源信息”展开版本 ID、段落 ID、核验状态。无段落证据的其他来源明确标注缺失，不补造全文。前景阅读窗继续显示合成/模拟提示。
- **问答**：可选条件默认收起，已选条件在摘要可见；提交、取消、检索计划、覆盖统计、错误和引用展开保持共享实现。
- **可返回比较**：顶栏“返回原版”进入 `/`，页脚维护入口进入 `/ingest`；`/ask` 与 `/events/:id` 保留，阅读窗另有“打开完整事件页”。演示参数沿这些链接保留。

## Do's and Don'ts

保持用户已确认的证据直接可读、来源元信息按需展开，以及原四页可访问。只减少界面中的重复入口和常显辅助内容；不要把省略侧栏理解为省略检索范围或能力边界。

本次只核对实现与记录，不将局部偏差升级为规范。已依据最终源码 `8d20a2a` 核对三个展开指示、清除按钮高度及日期对齐：日期文字采用显式独立元素，箭头与日期靠左，计数通过更高优先级的自动左外边距靠右；三个展开箭头已纳入减少动态效果规则。本段为源码核对结果，不替代独立视觉裁决。既有设计侧车的时间戳过期提示不在本次修复范围。
