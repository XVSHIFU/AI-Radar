## Overview

本轮保留“桌面阅读空间 · 云层切面 · 动作谱”：银蓝地面上使用白色阅读面、深蓝动作和安静的日期层级。日期组织阅读，抽屉组织核对证据，统计图组织库内分布；没有新增位图、装饰性大数字卡或新的品牌方向。

公众进入“统计与问答”先看到程序统计。实际页面顺序为标题与无 AI 说明、共用范围控件、完整匹配总数与日期范围、两种统计图、同范围提问、分页事件列表。点图会更改同一组筛选，列表与后续提问都使用该组条件。当前 `/ask` 与 `/preview/ask` 共用 `AskPage.vue`；差异来自外层导航与阅读宽度。

## Colors

沿用运行时颜色：银蓝背景、白色阅读面、深墨正文、灰蓝辅助文字、细浅蓝分隔和深蓝操作。日柱及分类横条使用深蓝表达数量，不额外引入表示风险、涨跌或排名的颜色。合成数据继续使用带文字说明的淡黄色提示；失败用实际错误文本配合原有错误色。

范围按钮以浅蓝底、边框和 `aria-pressed` 标明选中；首页分类保留原生单选语义，并在被选文字所在行使用浅蓝底。清除只在条件非空时出现，使用无底色、下划线的轻文字操作。

## Typography

字体沿用 Inter、苹方、微软雅黑和系统无衬线回退。主标题沿用既有大小层级；统计分节为 20px，事件列表标题为 18px、500 字重。原首页静态年份改为 20px、650 字重，日日期使用灰蓝 13px；预览首页的静态年份同为 20px。

统计总数、日期与图上数值使用等宽数字。柱值和分类计数直接显示，读取数值不依赖鼠标悬停；每张图附带可展开的普通数据表。日期表在月桶模式显示桶内实际起止日期，避免用整月标签掩盖边界天数。

## Layout

原首页年和日为静态文字，只有月份按钮可以折叠，保留月份 `aria-expanded`。最终样式覆盖取消旧的左侧年份列及纵线，年份回到普通文档流。计数仍明确为“已加载”，不能与总览的全范围精确总数混用。预览首页也采用静态年、日和月份折叠；两者保留各自既有阅读密度。

统计主体最大宽度为 1080px；原版继承侧轨布局，预览版受其 920px 外层内容宽度限制。图表在大于 900px 时并列，间距 24px，900px 及以下纵排。自定义日期和更多筛选使用可换行字段；常用条件收在原生 details 中。提问与事件阅读面桌面内边距为 22px 28px，紧凑布局为 20px。

日柱允许容器内横向滚动，保留每个日期至少 44px 的操作宽度，不把最长 31 个日标签挤成不可读小字。更长区间改用自然月桶。源代码把柱形的真实高度与按钮命中面积分离，零值保持零高度；柱形与数值标签从共同的按钮父元素继承计算高度。填充的宽度由两侧各 5px 的内缩确定，未再叠加百分比宽度。

## Elevation & Depth

阅读面继续使用原有柔和阴影；统计图为白色、14px 圆角的小阅读面，提问和事件区为 16px 圆角。抽屉保留纸面阴影与独立滚动正文。层次用于说明正在核查哪一层材料。

`EventDrawers` 的事件和来源均可直接阅读保存摘录；“来源信息”通过 details 展示版本、段落和核验状态，事件层的“来源详情”进入第二层。桌面活动来源层贴近右侧（24px），非活动父层右退至 56px，父层仅保留左侧边缘，正文与标题子内容隐藏。900px 及以下采用全屏覆盖。兼容用的第三层证据 dialog 仍在源码中，但当前普通证据阅读已前置到事件与来源层，不能把三次进入视为必须路径。

预览首页的 `PreviewReader` 是单层事件阅读抽屉：来源标题、链接、保存摘录直接列出，版本等信息内联展开；它没有独立来源第二层。其全屏断点仍为 700px。此实现差异已向根代理报告，未将预期中的一致层数写成既成事实。

抽屉保留既有短距离进入动作，减少动态效果偏好下关闭动画和过渡；月份指示符和 details 指示符只承担开合提示。

## Shapes

控件沿用轻圆角与细线，日期折叠指示符使用 CSS 边线，返回使用紧凑内联 SVG 加“返回”文字。抽屉头部没有另外的“关闭”文字操作。清除与返回降低视觉分量，但保留至少 44px 高的操作区域。未新增装饰图形、纹理或新的图标体系。

## Components

### 共用范围与统计语义

- 默认“今天”以 Asia/Shanghai 计算；“近7天”为今天及此前六天，“本月”为月初至今天，自定义区间最多 366 天。起止日期均包含。缺少日期、逆序和跨度过大分别显示校验文字，不发起统计。
- 分类、标题/摘要/实体关键词与重要度 4 及以上同时进入统计和列表过滤。统计接口为 `/api/v1/insights/summary`；分页列表独立请求，每次 10 条。统计总数来自整个精确匹配集合，不能由当前列表页估算。
- 统计按标准事件计数，同一事件的多个来源不各计一次；限定时间范围排除未知日期。总览表示当前库内收录，不能代表全网覆盖。
- 最长 31 天显示日柱，零事件日期保留；超过 31 天将每日计数加总为自然月桶，边界月仅计选定范围内日期。分类固定为六类并保留零项，横条按当前最大分类计数缩放；横条不是百分比占比图。
- 点击日柱将范围改为该日；点击月桶原样应用桶内实际起止日期，不将结束日期截到今天（`5f2cee2` 已复核）；点击分类横条设定分类。日期柱使用原生按钮与可访问名称，分类按钮包含名称和数值；数据表为阅读备选。源代码提供基础键盘可操作性，不等于辅助技术合规验收。

### 空态、失败与范围变更

总数为零时隐藏两张图，显示“当前范围暂无已收录事件”；默认今天的空态提供“查看近7天”，必须由用户主动选择，不能自动跳到 fixture 中有数据的日期。匹配事件区另有加载、读取失败及没有事件的文本状态。统计失败和列表失败分别保存，不把失败当作零条。

条件变动会立即清除旧总览与列表，取消旧请求并用请求代次防止迟到结果覆盖新范围；同时取消旧回答并清除旧结果和引用。新范围经过短暂输入防抖后查询，避免在新日期旁展示旧结果。

### 同范围提问与规则解析

“开始分析”使用共用筛选；原有检索范围、流状态、取消、错误、引用与覆盖字段继续保留。“按问题筛选”调用确定性 `/api/v1/query-plan`，先展示规则解析预览，只有点击“应用到总览”才更新分类与日期，并明确沿用当前关键词和重要度。

无法完整表达的实体条件、狭窄实体角色、自由文本或待澄清条件会阻止应用，不能只应用其中一部分后宣称完整理解。真实生成模型未配置时显示 `MODEL_UNAVAILABLE` 及说明；前端模拟流有明确标识。统计和规则解析无需 AI，不能因此宣称真实 LLM 生成链路已经接通。

### 抽屉与焦点

原生 dialog 的 Esc、轻量返回或外遮罩按活动层退出。遮罩点击先检查事件目标是 dialog 本身，再判断坐标是否在边界外，避免把内部留白和键盘触发的点击误认为关闭。事件与来源打开、关闭时保存可用触发点，返回后恢复焦点；背景阅读滚动位置有恢复逻辑。

全局显式焦点规则为 `:focus-visible` 深蓝轮廓（3px，偏移 2px），输入焦点仍可改变边框色；旧统一 pointer outline 已不在本轮源码。鼠标与键盘的浏览器实际绘制差异以独立交互检查为准，不只根据计算出的 outline 宽度判定。summary 沿用原生可聚焦行为。

- 不把尚未完成的真实日采集、标准事件发布、真实 PostgreSQL 或 LLM 验收写成已完成。当前 fixture 数据与模拟回答不能作为真实新闻或真实模型质量证明。
