# AI 革新雷达：设计与原型评测基线

状态：实施基线，2026-09-12。工程位置以本次工作区为准，覆盖方案中的旧 C 盘示例路径。

## 产品与信息层级

首页 `/`：品牌与导航 → 全库搜索 → 日期/分类筛选和已采用条件 → 服务端匹配总数 → 按日期排列事件 → 分页。全库态势独立标注统计范围及更新时间。每条事件包含标题、摘要、日期、分类、重要度、来源数量与证据状态。当天无数据时明确空态。

详情 `/events/:id`：标题与事实日期 → 中文摘要 → 相关实体 → 多来源报道 → 系统保存的原文版本与段落摘录 → 相关事件及原因。摘录可键盘展开；原文、翻译、摘要分别标识。

问答 `/ask`：问题和显式条件 → 处理阶段/取消 → 回答 → 引用来源 → 完整匹配数量、取回数量、总结数量、覆盖程度与限制。无资料、服务故障、未配置模型、预算不足、用户取消必须区别显示。演示流明确标识模拟，不能宣称真实模型已验证。

采集管理 `/ingest`：鉴权 → 来源健康 → 运行阶段、成功/失败计数 → 失败详情与重试 → actual/estimated/unknown 成本。管理凭据只保存在页面内存，不放入 URL、持久化存储或 VITE 配置。

## 视觉基线

中文使用系统字体栈 `Inter, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`，无外部字体依赖。正文 15–16px、行高 1.6；辅助文字至少 12px；主标题 28–36px。间距采用 4/8/12/16/24/32/48px。圆角 8/12/16px，界面最大宽度 1280px。

基础色：背景 #F6F8FA，面板 #FFFFFF，正文 #182230，次级文字 #526171，边框 #DCE3EA，品牌 #087F75，失败 #B42318，警告 #946200。所有颜色、字号、间距沉淀为 CSS 变量/Tailwind v4 theme。两候选可分别探索「编辑式资讯列表」和「研究工作台」，使用相同数据、接口、内容密度及功能。

响应式：1440px 主内容加辅助栏；768px 辅助内容收进主流；390px 单列、筛选可折叠、导航可换行，无横向页面溢出。控件触摸目标至少 44px；键盘焦点清晰；状态使用 aria-live；不得仅靠颜色传达状态。

加载：骨架不伪造新闻；筛选更新显示进度并取消旧请求；保留输入。空态解释范围且可清除条件。错误态保留条件并提供显式重试。流中断不得视为完成，不自动重发计费请求。

## 同条件原型评测

技术栈统一 Vue 3 + TypeScript + Vite + Tailwind v4。数据统一 `contracts/prototype-events.json`，明确为合成 UI fixture，不计入真实新闻、历史 gold 或采集验收。

Sol、Terra 各自独立 worktree 做一版首页。必须包含关键词、分类、日期过滤、匹配总数、分页、详情入口、加载/空/错误态切换。可用 fixture adapter 模拟服务端行为，但必须在页面标识演示数据。

评分：信息层级 25、可读性 20、筛选与反馈 20、移动端 20、键盘可访问性 15。先实际运行并在 390/768/1440px 验证再评分；构建或关键操作失败不得仅凭视觉选胜。选胜后保留一个持续前端负责人。
