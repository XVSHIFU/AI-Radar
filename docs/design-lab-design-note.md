## 状态与依据

用户当前要求预览 A/B/C 并选择，尚未批准正式 UI 重设计。这份说明记录独立 `/design-lab.html` 的现状，不建立新品牌、不替代根目录 `DESIGN.md`，也不生成或刷新设计 sidecar。

核对依据为当前 HTML 内联样式及主要渲染、筛选、摘要、抽屉函数，另参考 `PRODUCT.md`、`DESIGN.md`、`docs/design-lab-plan.md` 和初审 `docs/design-lab-finish-review.md`。初审结论为 fix；本说明只记录源码中可见的后续实现，最终视觉结论交由独立 reviewer。documenter 以真实独立子代理执行，角色文件中的 inline 降级前提不适用。

## 平面与视觉词汇

统计、筛选和动态内容直接落在底面，使用细分隔线组织阅读；动态事件没有各自浮起的白卡。阴影仍用于事件抽屉和 B 摘要浮层，因此不能把“全站无阴影”写成规则。

预览浅色底为 `#f6f9fc`、正文为 `#132d49`、主要交互蓝为 `#17639f`；深色切换使用 `#0d1b29` 底、`#e8f2fa` 正文和 `#82c7f7` 交互蓝。这些仅是候选页的实际值，不是已采用的正式主题。面积图与矩阵另外使用字面色值，未完全随主题令牌变化。

字体为系统无衬线及 Microsoft YaHei 回退，正文 15px / 1.55；主要标题桌面 26px、手机 23px，摘要数字 28px，辅助信息 12–13px。输入与主要按钮圆角 8px，矩阵格 6px，事件标签为胶囊。容器最大宽度 1380px，桌面左右留白 28px，手机 15px。这里只说明实现，不将尺寸偏差提升为可访问性标准。

## 三个同等候选

| 候选 | 统计结构 | 摘要入口与呈现 | 当前源码依据 |
| --- | --- | --- | --- |
| A 流向总览 | 分类到日期的事件关系；节点标注数量，路径宽度随计数变化；点击节点或路径限定分类、日期或两者 | 桌面右侧 290px 问答栏，可收起再展开；手机初始化时收起侧栏并保留展开入口，展开后问答区域置于图表之前 | `renderFlow`、`setFocus`、`askCollapse` / `askOpen` 及移动样式 |
| B 时间潮汐 | 按日、按分类堆叠面积；图例与数据表补充数值，提供日期播放与暂停 | 桌面底部输入条；查看摘要后显示固定在视口底部的有界 sheet，手机贴底、最高 45dvh；可见收起按钮隐藏面板并恢复触发按钮焦点，Esc 亦可隐藏 | `renderTide`、`areaPath`、`answer`、`.tide-sheet` |
| C 分类矩阵 | 日期 × 六类事件的计数格；列数跟随当前日期数量，单格选择同时限定日期与分类 | 选格后在矩阵下方就地显示日期、分类、数量与摘要按钮；摘要就在该上下文内展开 | `renderMatrix`、`filtered`、`matrixContext` |

A 流向明确不表示来源采集漏斗。B 面积表达每一天各分类数量的堆叠，并非跨日期累计总量；源码播放时推进光标，也将尚未推进日期的值置零，页面文案已改为“按日期播放图表变化”。C 通过上下文文字说明所选日期和分类，并按 `state.focus` 给对应格子添加持续选中轮廓及 `aria-pressed` 状态。

## 手机与共用交互

760px 及以下，A 图表保持 640px 宽，在图表区域内部横向滚动；B 图表保持 760px 宽，通过方案容器内部横向滚动；C 在矩阵容器内横向滚动。此处记录实现策略，不据源码声称手机文字可读性或溢出问题已通过视觉复验。

顶部提供统计总览、AI 动态、来源说明以及 A/B/C 切换，三个候选同等可选。日期按钮对应固定样本范围：近 7 天为 2026-09-08 至 09-14，本月为 09-01 至 09-14；自定义起止包含边界。分类、日期和图表焦点触发完整渲染时，`clearContexts` 会清除已展开摘要与 C 上下文，避免沿用旧集合文本。

动态区另有搜索与分类条件、静态年份、可折叠月份、按完整日期分组的事件和加载更多。事件按钮悬停变色并附箭头，不使用下划线反馈。事件抽屉提供返回、遮罩关闭、Esc、焦点回归和 Tab 边界处理；这些是源码观察，不等于辅助技术验收。

图表附可展开数据表，矩阵格同时显示计数和日期／分类可访问名称；流向节点与路径有键盘 Enter / Space 处理。`prefers-reduced-motion` 下 CSS 关闭过渡和动画，播放按钮处理函数直接返回。部分导航为 38px、筛选按钮和输入为 42px，不能据主要按钮 44px 宣称整体满足产品触摸目标基线。

## 数据与能力边界

全部统计、事件和摘要来自页面内固定生成的 42 条合成样本，覆盖 2026-09-01 至 09-14，六个分类。没有真实新闻、真实采集统计或全网覆盖承诺。

“查看摘要”只按当前筛选集合计算条数、分类数及前五条样本，不理解或发送问题输入。源码无模型调用或数据请求；来源说明和摘要明确标注未调用 AI。

来源说明列出 Hugging Face 博客、arXiv cs.AI、Google Research、AWS ML、NVIDIA Technical Blog，并标为尚未接入或启用。页面只有维护职责的说明，没有实际管理操作入口；不能把文案当作候选源已接通或管理功能已交付的证据。

## 未固化为正式规范的事项

初审中的手机可读性、C 网格、摘要范围及 B 展开结构需要依据后续实际截图和行为复验裁决。本说明不撤销 fix，也不宣称其仍全部复现。最终源码已补充 B 可见收起及触发焦点恢复、C 持续选中样式与状态、B 播放文案修正。手机 A 在初始化媒体查询匹配 760px 及以下时真实调用收起按钮，默认隐藏侧栏并显示展开入口。上述早期缺项不再列为当前源码缺陷。仍不将候选页的字面图表色值和不足 44px 的部分控件尺寸固化为正式设计规范。

正式采用哪一方案、是否采用深色及其最终交互，仍由用户选择后另行实施。根目录设计系统、sidecar 与正式 Vue/API 源码不在本次说明的修改范围。

用户在选择页进一步要求全站随时唤起助手，最新全站助手候选见design-lab-plan.md及design-lab-global-choices.json。此处源码记录仍描述已存在的局部交互草案，不代表全站助手已实现。最终视觉裁决仍有B收起位置partial，详见design-lab-finish-verdict-final.md。
