## 已交付的工作流

管理员进入 `/ingest` 的内容工作台，登录后从冻结文章中选最多 5 篇，复制或下载带任务编号、原文段落标记的提示词，自行交给网页生成器。将返回的 JSON 或 JSON 代码块粘贴导入，逐篇检查错误、修改草稿，再确认发布；无关文章可显式标为跳过。导出总量受 48 KB 限制，服务器保存实际导出的段落范围，并检查逐字引文、实体、类别和事件日期。重复导入不会覆盖更新的草稿，重复发布只返回同一事件。手动路径不创建伪造的模型调用记录，也不调用本站模型 API。具体接口见 [内容工作台 API](content-workbench-api.md)。

可选的内容 Agent 使用独立的模型配置文件、任务和用量账本，不覆盖公众研究助手配置或同 IP 48 小时 5 次的额度。自动模式、自动发布均默认关闭，每日文章及输入/输出 token 上限默认为 0；必须显式配置专用 API Key、非零上限并选定本批文章。每篇最多一次模型调用、并发 1。pi 内容运行时没有 shell、Python、数据库写入或管理员工具，模型只生成草稿，发布由后台事务完成。调用结果或用量不明时，保留保守预算预留并暂停队列，不自动重试或切换收费供应商。

参考资料只整理为人工审查材料：修复 8 处 CSV 错列，隔离 14 条错误实体映射，生成 2 个默认禁用的官方来源种子；未将 64 个候选来源整体启用。接入方式和禁用状态见 [参考数据受控接入](content-reference-import.md)。
