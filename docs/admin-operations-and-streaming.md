# 后台交互、通用模型配置与真实流式回答验收

日期：2026-09-15。开发环境为 Ubuntu 私有网络服务；此记录补充上一次后台验收。
专用 Agent 编排尚未实现，见 [待审阅的开发方案](research-agent-plan.md)。

## 已交付行为

- 来源支持全选、选中探测和全部探测；客户端最多并发2个，显示进度圈、逐项状态与最终统计。
  可停止排队；已经开始的探测可以完成。会话过期后停止继续提交。
- 单个与批量探测均保留现有页面，只刷新来源数据，不重置模型表单。
  探测按钮有加载反馈；不会以页面清空的方式显示忙碌。
- 采集运行状态使用中文。错误先显示403拒绝访问、429限流等通用说明，
  原始诊断默认折叠；展开使用完整行宽和有限高度，避免狭长日志撑高页面。
- 模型配置支持 DeepSeek、OpenAI、通义千问、Moonshot 预设及自定义 OpenAI Chat Completions 兼容服务。
  预设填写服务商、URL和模型，均可继续编辑；保存后被后续提取、问答和后台测试读取。
  这不是多账户轮换或故障自动切换；原生 Anthropic Messages 等不同协议还未适配。
- 更换服务端点必须重新提供密钥；不把原服务密钥发送给新地址。
  服务端密钥不回传、不存浏览器；旧配置与环境变量兼容。
- 连接检查调用模型列表接口，不伪造聊天内容。回答测试显示实际 system/user 消息、
  实际返回或简明失败原因，并记录真实 usage。测试使用已保存配置。
- 小助手使用 POST /api/v1/ask/stream 获取真正的上游增量正文。
  正文16px、行高1.7；角色/范围和诊断保留紧凑展示，详细内容默认折叠。
- sources 先暂存，成功 done 才发布正式引用；断流/错误/取消保留已收到的草稿并标明未完成。
  不自动重试付费调用，取消后提供商是否已经计费不能据此推断。
- Markdown、浏览器本地历史、Enter发送/Ctrl+Enter换行继续保留。

## 验收证据

- 后端：233项测试全部通过，包含临时真实 PostgreSQL 集成测试；Ruff、mypy与冻结OpenAPI检查通过。
- 前端：38项测试通过，类型检查与生产构建通过。
- 浏览器实际批量探测：8/8入口可访问，观测最大并发为2。
- 单来源探测：进度图标出现，来源区和8个原列表节点全部保留。
- 日志默认收起，桌面诊断行宽1038px；390px窄屏无横向溢出。
- 预设填充：OpenAI自动填入官方/v1地址及gpt-4.1-mini；未保存的测试密钥在切换后清空。
  未保存其它提供商配置，也未向其它提供商发送现有密钥。
- 真实Flash短测试1次：输入46、输出6、合计52 tokens，界面显示实际请求和返回。
- 真实SSE接口1次：首段0.625秒、总耗时1.172秒，133个正文片段，4条有效定位引用。
  用量输入875、输出133、合计1008 tokens。
- 实际浏览器问答1次：从834ms开始逐段渲染，共观测159次正文增长，完成4条引用核对。
  用量输入875、输出159、合计1034 tokens。两次问答仅使用公开NVIDIA博客事件，无私人会话历史。
- 随后在浏览器用固定模拟响应做功能回归：完成后引用保留、展开与收起正常；
  缺少done时保留正文草稿、清空正式引用并显示中断。该回归不调用模型。
- 窄屏助手展开后宽390px，输入框下沿826px位于844px视口内，背景设为inert。
- 本轮视觉检查限定为两轮批量检查；测试过程中修正了单探测刷新、引用状态接线与失败草稿展示问题。

本轮上述三次真实模型调用合计2094 tokens；费用未获提供商返回，保持未知，不估算。
其余提供商仅验证配置、协议和模拟回归；没有对应密钥，未做真实调用验收。

## 保留边界

入口健康不代表所有文章均可访问，旧403/限流记录保留用于定位。当前事件日期、去重与检索相关性
仍是下一阶段重点。有效引用编号与原文定位不等于结论已完成独立语义核验。
复杂自然语言计划、工具编排、图表生成、向量检索和公网生产加固依照后续方案实施。
