# B 轻量控件正式接入

入口：[AI 动态](http://127.0.0.1:5175/?demo=1) · [统计与问答](http://127.0.0.1:5175/ask?demo=1)。

用户在批准独立 B 预览后确认接入现有工程。本轮保持首页为 AI 动态、统计为 /ask、浅色阅读空间、真实 API 和原有 IndexedDB 会话；未进行部署或模型接入。

## 结果

- 共享 compact-controls.css：主操作实色、筛选浅底、辅助操作无框；桌面普通按钮32px、辅助28px、手机44px。分类保留原生 radio 语义并以紧凑选中样式呈现。
- 共享 DateRangePicker：首页和统计使用同一日期入口；快捷范围、单月日历、起止字段、应用、取消、外部点击与 Escape；日期草稿在应用前不触发查询。统计默认今天，支持近7天、近30天、本月、自定义，最多366天含端点；首页可不限或单边日期。
- 历史从常驻按钮堆叠改为列表与每行更多菜单，支持原有会话切换、重命名对话框、导出、删除。真实存储继续是 IndexedDB，预览 localStorage 未迁入。
- 两个拖宽入口改为6px separator，不再受历史按钮宽度影响；修正历史拖动方向，保持总宽最多半屏。
- 热力格3px圆角、相对最大值的红色色阶、数字和辅助标签、轻微动画；手机44px点击目标并可横向滚动。A/B图表保留。
- 前端显式 demo=1 共1061条合成事件（原32条结构样本保留，加1029条覆盖60天的样本，其中一天零事件）；截至本轮日期，近30天569条。列表、详情、统计共用数据。后端32条fixture及真实接口未替换。
- 共享抽屉CSS改为应用入口加载，修复直接访问统计页时抽屉无样式；事件继续显示在助手左侧。
