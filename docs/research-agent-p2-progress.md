# 专用 Agent P2：候选运行时与可信模型网关

2026-09-16。继承 [专项增补方案](research-agent-v2.md)；本记录不是完整 Agent 上线验收。

## 已实现的候选代码

- `agent/runtime/` 使用实际安装的 `@earendil-works/pi-agent-core` 0.85.1 和自定义模型流，直接与间接依赖锁定；安装禁用脚本。独立 Node 服务每轮创建新 Agent，显式注册七个研究工具，不注册 shell、文件操作、插件发现或 Python。Node 不持有模型供应商密钥。
- 运行时 HTTP 接口限制身份凭据、输入体积、并发、截止时间和客户端断连；默认仅监听回环地址。真实 pi 循环按串行工具执行，上限三次模型调用、四次业务工具、两次 Skill，取消不自动重试。
- `research_guard.py` 在 Python 侧独立实施一次运行的随机能力令牌、截止时间、调用序号、预算预留与结算，以及模型签发的工具调用 ID/原参数匹配。重启后能力令牌失效，不能由客户端恢复。
- `research_stream.py` 新增受限工具流适配器，保留原普通问答适配器禁止工具的行为。按 SSE 帧读取，正文立即输出，工具参数分片只有在完整结束后才组装；拒绝重复 JSON 键、非有限数值、非法调用 ID、重复调用、过大响应、缺失结束标志。截断参数不可执行；缺失 usage 保持未知，不伪造零。取消关闭上游，无自动重试。
- `research_gateway.py` 提供可信会话核心，系统消息、用户已接纳问题、工具 Schema、模型回复和工具执行结果由后端构造，不接收 pi 自造的对话或权限。无效工具调用生成受控错误并在后端记录，避免 pi 本地拒绝后下一轮一直等待未执行工具。记账接口为必需依赖；接纳失败不调用模型，结算失败撤销权限。

协议依据：供应商支持 SSE 内容分片与工具调用，usage 可能随结束内容块返回；适配器也覆盖独立 usage 块。参考 [DeepSeek Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。这里只实现并测试了协议解析，**没有以文档存在代替真实模型兼容验收**。

## 本轮继续完成：范围工具、内部 HTTP 与多次调用账本

- `research_tools.py` 实现七个受限研究工具。每轮使用独立的 PostgreSQL `REPEATABLE READ READ ONLY` 事务，查询超时 10 秒、空闲事务超时 95 秒，运行权限继续受 90 秒截止限制。检索返回分页条数与完整范围总数；统计直接聚合授权范围，不从分页推算。日期统计排除未核验、未知和冲突日期；跨期比较处理零基期、不同天数、区间重叠和未知采集缺口。
- 证据来自本轮快照中的文章版本，必须定位到段落并通过已有 quote hash 校验。事件 ID、游标、数据集只在原运行和范围内可用，取消或退出后销毁临时索引。图表仅引用本轮数据库数据集；Skill 由服务端从固定规范包加载，没有文件路径或安装接口。
- `research_http.py` 实现内部模型/工具回调路由和限量活跃会话注册。检查随机能力令牌、严格请求字段与体积；pi 附带的 context 不进入供应商请求，后端自行维护真实系统规则、历史和工具结果。该路由尚未挂入线上应用，后续公开网关必须继续禁止访问 `/internal/`。
- `research_ledger.py` 与迁移 `0012_research_model_calls` 为每次付费模型调用持久化序号及输入/输出预留，并复用 `llm_calls` 记录实际用量，供应商费用未知时不编造金额。数据库锁独立拦截重复调用、上一调用未结束、次数与累计预算超限。公开问题结算现改为在父记录锁内汇总子调用；取消与新调用竞争时不会释放已经接纳的调用费用。此结算变更仍只在候选源码中。
- Ubuntu 的 Node 22.22.1 未编译原生 TypeScript 支持。运行时现先通过 TypeScript 编译，再执行 `dist/src/server.js`，不依赖可选的类型剥离功能，也未改动宿主 Node 版本。
