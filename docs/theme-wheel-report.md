## 实现
保留原五套配色，加入雨后灰蓝、浅苔橄榄、玫瑰豆沙、杏纸琥珀、梅子暮紫、海盐湖蓝、玉石竹青、奶油可可、鸢尾靛蓝、珊瑚浅沙、月白石墨，共16套。
导航左下角展开四分之一轮盘；拖动与滚轮仅浏览，点击才应用。提供前后按钮、方向键、Home/End与Enter；Escape/点击空白关闭，恢复触发按钮焦点。
全局共享颜色令牌覆盖主页、统计、导航、抽屉、日期弹层、输入框和研究助手。热力图的数值红色色标及成功/警示/错误语义不随主题改变。
选择从色块位置扩散至全页，650ms；减弱动态与不支持View Transition时直接切换。偏好仅保存主题ID，无注册与模型调用；存储失败不影响当前使用。默认雾白钴蓝。
