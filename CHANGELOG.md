# Changelog

## v0.1.0 — local release candidate

- Automatically collect source titles, excerpts and links without model calls.
- Browse a unified feed of original articles and existing curated items, with search, filters and publication-date statistics.
- Hide or restore articles in the simplified administrator workspace; retain optional manual editing and content generation.
- Make collected articles available to the optional research assistant, distinguishing feed excerpts from saved body evidence.
- Provide configurable Docker Compose deployment, local image export, persistent data and backup/restore commands.

GitHub publication, registry push and deployment to a new cloud server are intentionally deferred until the maintainer supplies the destinations. Optional AI features require separate configuration; Python execution is not enabled by the basic release.
