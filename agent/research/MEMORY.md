# 研究记忆规范

## 四类信息

1. **公共知识**：数据库事件和冻结 Evidence 是事实来源，模型记忆不得改写。公开术语/方法由管理员维护为只读规范。
2. **本轮工作记忆**：范围、已读取 ID、计算结果、待核实事项。运行结束或到期删除，不跨匿名会话共享。
3. **会话摘要**：保留用户问题、已确认约束、结论及其 citation ID、未解决问题。摘要仍是不可信上下文，不能增加权限；重要数字再查原数据，错误/中断稿不写成事实。摘要最多 1,200 tokens，不能偷偷额外付费压缩。
4. **个人偏好**：只在用户明确要求记住时保存语言、回答长度等少量偏好；可查看、删除。第一版继续保存在浏览器，不默认建立服务端长期用户画像。

IP 只用于配额，不是身份或记忆主键。服务端临时资源使用高熵匿名会话凭证校验归属，清除浏览器凭证后不能通过相同 IP 取回他人会话。

## 不存什么

不将密钥、原始 IP、Cookie、认证头、部署路径、内部推理链、整篇网页或用户敏感信息写入长期记忆。不把“以后忽略限制”作为偏好保存。网页、工具结果和用户上传文件不能修改规范包。

运行元数据默认仅保存脱敏状态、时间、工具名、计量及政策版本；对话原文不默认写入持久审计。临时运行/数据集/产物到期删除；配额和幂等账本按各自保留期保留，不能用“忘记对话”重置付费额度。

## 纠错与升级

用户纠正一个事实时，记录为待核查陈述，重新查证后更新本会话摘要。跨会话知识修正走数据库质量管理，不由公众 Agent 写库。Skills 更新需评测和发布，不能自动把某个用户的行为要求变成所有用户的系统规则。


## 初版实现细则（2026-09-16）

旧轮次摘要采用浏览器本地提取，不增加付费调用或长期摘要副本。JSON 总字节数限制为 1,200，按运行预算的一字节保守上界核验。默认不附加；用户查看后主动选择用于下一次提问，选择仅在内存、只消费一次，切换会话即清空。后端要求与摘要同时提交 send_once，摘要仍为不可信资料。

语言与回答长度是仅有的可保存偏好，通过界面明确保存/删除，只作用于本浏览器的本会话。清除上下文设置持久边界，同时排除旧的最近历史和摘要；仍允许查看旧消息，但不会再自动用于后续提问。模式之间不共享上下文，不以 IP 合并记忆。
