# SVG provenance

The user selected original candidate 03, “时间脉络” (Timeline), for the production navigation mark and favicon on 2026-09-15.

- `frontend/src/RadarMark.vue` uses the project's original timeline geometry: a vertical stem, two horizontal branches and three circular event nodes. It inherits the active theme through `currentColor`, with node outlines using the paper color.
- `frontend/public/favicon.svg` adapts the same geometry for a 32 × 32 favicon, using a pale blue and lavender mark on a transparent canvas. It is a project-created SVG, not an emoji or a vendor logo.
- The eight original SVG concepts remain available on `/brand-preview` for comparison history. Candidate 03 is the selected production mark; the other candidates are not additional production identities.

`AssistantMark` continues to use Lucide `bot-message-square`, obtained through Iconify. The original Lucide `radar` asset is retained here as historical source material; it no longer describes the selected production `RadarMark` or favicon.

- [Lucide radar through Iconify](https://icon-sets.iconify.design/lucide/radar/)
- [Lucide bot-message-square through Iconify](https://icon-sets.iconify.design/lucide/bot-message-square/)
- [Lucide upstream](https://github.com/lucide-icons/lucide)

Original downloaded SVGs and the upstream license remain in this directory. The independent direction preview also uses project-created geometric navigation SVGs.

The six self-hosted fonts belong only to the fixed `/type-preview` typography specimens. Their sources, subset limitations, licenses and hashes are documented separately in [the type-study font inventory](../type-studies/fonts/README.md). Production uses the selected B pairing; its separately self-hosted font files are documented in `../fonts/editorial/README.md`.

This file records asset provenance and the user's selection; it does not claim that the current integration has completed final validation.
