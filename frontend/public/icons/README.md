# SVG provenance

The production RadarMark and AssistantMark components use Lucide `radar` and `bot-message-square`, obtained through Iconify:

- https://icon-sets.iconify.design/lucide/radar/
- https://icon-sets.iconify.design/lucide/bot-message-square/
- https://github.com/lucide-icons/lucide

Original SVGs and the upstream license are retained in this directory. Components inherit the active theme through currentColor. The favicon is a custom simplified radar geometry for small sizes; it does not use emoji or a vendor logo. The independent direction preview uses custom geometric navigation SVGs with the same stroke language.
